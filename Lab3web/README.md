
# Laporan Praktikum 3: CSS Dasar

## 1. Tujuan Praktikum

- Memahami penggunaan CSS pada halaman web.
- Memahami Inline CSS, Internal CSS, dan External CSS.
- Memahami penggunaan selector ID dan class.
- Menerapkan CSS untuk mengatur tampilan halaman web.

## 2. Dasar Teori

CSS (*Cascading Style Sheets*) adalah bahasa yang digunakan untuk mengatur tampilan halaman web, seperti warna, ukuran teks, jenis huruf, jarak, dan latar belakang.

CSS dapat diterapkan melalui tiga cara, yaitu Inline CSS, Internal CSS, dan External CSS. Inline CSS ditulis langsung pada elemen HTML, Internal CSS ditulis menggunakan tag `<style>`, sedangkan External CSS ditulis pada file `.css` terpisah dan dihubungkan menggunakan tag `<link>`.

## 3. Alat dan Bahan

- Laptop atau komputer
- Visual Studio Code
- Web browser
- HTML dan CSS

## 4. Langkah-Langkah Praktikum

1. Membuka Visual Studio Code.
2. Membuat file `lab2_css_dasar.html`.
3. Menambahkan struktur HTML yang berisi header, navigasi, bagian intro, paragraf, dan tombol tautan.
4. Menambahkan Internal CSS untuk mengatur jenis huruf, ukuran judul, warna teks, dan tampilan header.
5. Menambahkan Inline CSS pada paragraf.
6. Membuat file `style_eksternal.css`.
7. Menghubungkan file CSS eksternal ke dokumen HTML menggunakan tag `<link>`.
8. Menambahkan CSS untuk mengatur navigasi, tautan, efek hover, bagian intro, dan tombol.
9. Membuka file HTML melalui browser untuk melihat hasilnya.
10. Melakukan eksperimen dengan mengubah dan menambahkan properti serta nilai CSS berdasarkan CSS Cheat Sheet pada modul.

## 5. Hasil Praktikum

Halaman web berhasil dibuat menggunakan HTML dan CSS. Halaman terdiri dari header, navigasi, bagian intro, paragraf, dan tombol tautan.

Internal CSS digunakan untuk mengatur tampilan header dan judul. Inline CSS digunakan untuk mengatur paragraf, sedangkan External CSS digunakan untuk mengatur navigasi, latar belakang intro, tautan, dan tombol.

Eksperimen dilakukan dengan mengubah dan menambahkan properti CSS untuk mengetahui pengaruhnya terhadap tampilan halaman web.

## 6. Kesimpulan

Praktikum ini memberikan pemahaman mengenai penggunaan CSS untuk mengatur tampilan halaman web. Inline CSS, Internal CSS, dan External CSS memiliki cara penulisan yang berbeda. Selector ID dan class membantu mengatur elemen tertentu, sedangkan perubahan properti CSS dapat menghasilkan tampilan halaman web yang berbeda.
